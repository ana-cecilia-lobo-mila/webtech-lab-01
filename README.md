## Interactive Features

### Hobby Collection
The hobbies section displays a collection of my hobbies, which can be filtered by typing in the search bar or selecting a category from the dropdown menu.

### Add a Hobby
The "Add Hobby" button above the hobby collection opens a form where you can enter a hobby's name, category, description, and image URL to add a new hobby to the collection.

### Expand Hobby
Each hobby card has a "More" button that can be clicked to enlarge its description, and clicking it again returns the text to its original size.

### Currently Listening
The "♫ Currently listening" bubble on the page can be clicked to show or hide the song I am currently listening to.

### Contact Form
The contact form validates each field when it is submitted and displays an error message next to any invalid field. Fill in all fields correctly and submit the form to see the confirmation message.
